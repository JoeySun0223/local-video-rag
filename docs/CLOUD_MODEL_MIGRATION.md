# 将本地模型替换为云端同类服务

知识资产层与模型调用层应保持分离。迁移云端时不要改变数据库句子、章节、Chunk和视频时间结构，只替换Provider适配器。

## ASR与时间对齐

云ASR必须返回真实文本及可追溯的字、词或句级时间戳。适配后仍需满足本项目句子契约：连续ID、非空完整句、整数毫秒、`end > start`、时间单调且不重叠。只有全文没有时间戳的API不能直接替代当前方案；不得按字数均匀伪造时间。

建议新增`CloudASRProvider`，输出与本地`ASRResult`相同的结构，并记录服务商、模型版本、请求ID、音频哈希、时间戳方法、重试和错误。云端成功后仍保存原始响应以便审计。

## Embedding

云Embedding接口需要记录模型名、版本、维度、归一化方式和距离函数。只要模型发生变化，就必须对全部Chunk重新生成文档向量；不能用旧文档向量配新query模型。

## Reranker

云Reranker应接收`query + 精确Chunk正文`并返回每个候选的独立相关度。更换服务后需要重新校准拒答阈值，分数不能直接沿用本地BGE Reranker阈值。

## 回答LLM

当前使用独立 llama-server 的OpenAI兼容`/v1/chat/completions`。云端若提供兼容接口，可以把`base_url`、模型名和认证头改为云Provider配置；仍必须使用结构化JSON、证据Chunk ID白名单、答案非空校验和证据不足拒答。云端API密钥只能放环境变量或未提交的`.env`/`config.local.yaml`，不能写进仓库。

## 数据安全

上传视频、音频、转写或Chunk前需要确认资料是否允许离开本机。生产环境应配置TLS、最小化上传内容、超时、指数退避、限流、费用上限和日志脱敏。若只把最终候选Chunk发送给云回答模型，暴露范围会小于上传完整视频，但仍属于向第三方发送知识库正文。

推荐分别实现`local`和`cloud` Provider，通过配置切换；数据库和知识资产格式保持不变，以便随时切回完全本地运行。
